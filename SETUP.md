# Install the upgraded README

1. Download and extract this ZIP.
2. Open your existing `red-khann` profile repository.
3. Upload the new `README.md` and the complete `cards/` folder to the repository root.
4. Keep your existing `resume.pdf` in the repository root so `./resume.pdf` continues to work.
5. Commit the changes to the default branch and open your GitHub profile.

## Important notes

- The avatar uses `https://github.com/red-khann.png`, so it automatically displays your current GitHub profile picture. To use a different portrait, add an image to the repo and update the avatar URL in README.md.
- The EduMetricsPro and RISA links use the real URLs from your current README.
- Weatherly currently links to your repositories list because its exact repository URL was not included in the supplied README. Replace that link when you confirm the repo URL.
- The custom cards contain CSS animation. GitHub may sanitize or restrict some SVG animation features in README previews. Check the rendered profile after uploading; if animation is removed, we can switch to a compatible alternative.
- GitHub stats and activity graph images are served by third-party services and may occasionally be unavailable.
- Stage 1 is visual only. Python automation and GitHub Actions will be added separately in Stage 2.
